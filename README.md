📚 Жастар арасындағы сленгті орынды қолдану мәдениеті
📌 Жоба туралы

Бұл веб-жоба жастардың тіл мәдениетін дамытуға және сленг сөздерді саналы әрі орынды қолдануға бағытталған ақпараттық ресурс болып табылады.

Жоба барысында сленг ұғымы, оның жастар тіліндегі орны, қолданылатын және қолданылмайтын жағдаяттар, нақты мысалдар мен практикалық ұсыныстар қарастырылады.

🎯 Жобаның мақсаты

Жастардың сөйлеу мәдениетін арттыру

Сленг пен әдеби тілдің айырмашылығын түсіндіру

Тілдік жағдаятқа сай дұрыс сөйлеуді қалыптастыру

Ана тіліне деген жауапкершілікті күшейту

🗂 Жоба құрылымы

Жоба бірнеше HTML беттен тұрады:

🔹 1. index.html

Басты бет.
Жобаның жалпы сипаттамасы және сленг туралы қысқаша ақпарат беріледі.

🔹 2. sleng.html

Сленг ұғымы, оның ерекшеліктері және жастар тіліндегі орны қарастырылады.

🔹 3. situacia.html

Сленг қолданылатын және қолданылмайтын тілдік жағдаяттар көрсетіледі:

Бейресми орта

Ресми орта

Әлеуметтік желілер

Білім беру мекемелері

🔹 4. misal.html

Сленг сөздер мен олардың әдеби тілдегі баламалары ұсынылады.
Мысалы:

«Краш» — ұнайтын адам

«Топ» — өте жақсы

«Хайп» — қызу талқылау

«Рофл» — қалжың

🔹 5. usynys.html

Тіл мәдениетін сақтауға арналған практикалық ұсыныстар мен қорытынды бөлім.

🎨 Дизайн ерекшелігі

Жоба заманауи әрі эстетикалық стильде жасалған.
Негізгі дизайн ерекшеліктері:

Түстер үйлесімділігі

Қарапайым және түсінікті интерфейс

Навигациялық мәзір

Карточка (card) элементтері

Бейімделген (responsive) құрылым

CSS файлдары:

style.css

sleng.css

situacia.css

usynys.css

Қосымша кітапханалар қолданылмаған. Жоба таза HTML және CSS негізінде жасалған.

📖 Жобаның маңыздылығы

Сленг — жастар арасында кең таралған тілдік құбылыс.
Алайда оны орынды қолдану — тіл мәдениетінің маңызды бөлігі.

Бұл жоба:

Сөйлеу мәдениетін қалыптастыруға

Әдеби тіл нормаларын сақтауға

Жастардың тілдік сауаттылығын арттыруға бағытталған
